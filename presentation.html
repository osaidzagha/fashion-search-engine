Engineering

Key Technical Challenges

🛡️ Zara Akamai Bot Protection
Zara's CDN detects headless browsers and geo-redirects Turkish visitors to a location-select page.

Solution: Geo-warmup helper visits homepage → category → harvests Akamai cookies → transplants into all scraper pages. Combined with Puppeteer Stealth Plugin to spoof browser fingerprint.
⚡ Request Interception Crash
Puppeteer threw Request Interception is not enabled when pages shared an interceptor.

Solution: Clear page ownership rules — attachRestrictiveListener / attachPermissiveListener helpers with a safeWipe cleanup pattern.
🌎 Render CPU Timing on Cold Start
Render's free tier has slow CPU hydration — scrapers returned 0 product links because JS hadn't rendered the product grid yet.

Solution: Extended wait times + explicit [class*="product-grid-product"] container wait before extraction.
📋 Obfuscated CSS Class Names
Zara obfuscates its CSS class names on every deploy, breaking selector-based department navigation.

Solution: Switched selectDepartment to match by textContent only — class-agnostic and deploy-proof.

Features

Key Features — Backend & Data

🕷
Stealth Scraper Pipeline
Puppeteer Extra + Stealth Plugin bypasses Akamai. Cookie harvesting (geo-warmup), request interception, randomized jitter delays.
⚡
Delta Skip & Smart Modes
Full mode scrapes all. Daily mode skips recently-seen products, focuses on volatile categories (sale, new, trending).
🛡️
Circuit Breaker
5 consecutive failures trigger automatic circuit break. Smart retry with session recycling on bot-wall / timeout detection.
📋
OOS & Ghost Detection
Products unseen for 14+ days automatically marked unavailable. Stale-detection sweep after every scrape.
🔔
Price Alert Queue (BullMQ)
After each scrape, BullMQ identifies price drops, cross-references watchlists, sends batched email alerts (50/batch).
📬
Weekly Digest Emails
Automated weekly email: top 5 discounted products of the week via Brevo in batches of 50.
🔒
Auth System
Local register with OTP email (30min expiry, TTL index) • Google OAuth via Passport • 30-day JWT • Forgot/reset flow.
⚙️
Admin Dashboard
KPI metrics, brand breakdown, scraper status tracker, start/stop controls, activity log, campaign hero manager.

Technical Deep Dive

Smart Search Engine

MongoDB Text Index
Weighted: name (×10), brand (×5), color (×3), desc (×1)
TextScore-based relevance sorting
Compound indexes for fast filter + sort
Synonym Expansion
"jeans" → "denim, jean"
"pants" → "trousers, chino, cargo"
"sweater" → "knitwear, pullover, jumper"
Exclusion Rules
Search "shirt" excludes jacket, coat, blazer, dress — prevents cross-category noise.
Sort Modes
Relevance — MongoDB text score
Newest — by scrape timestamp
Lowest / Highest — price ASC/DESC
Discount — computed % via aggregation
Trending — products with price movement
Dynamic Facets
Every search runs a parallel MongoDB $facet aggregation computing available sizes & colors for the result set.
Autocomplete
Real-time suggestions from text index — debounced, deduplicated, title-cased. 6 max.
